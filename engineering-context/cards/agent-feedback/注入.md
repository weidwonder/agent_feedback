# 业务域卡 — agent-feedback › 注入

## 职责
命令行工具：保存本机实例地址与登记令牌；把反馈模块写进宿主 skill 源头目录，在 SKILL.md 末尾追加引导语，并向服务登记该 skill 名。任一步失败回滚宿主目录。

## 权威实现与对外接口

| 能力 / 入口 | 权威实现（cite） | 类型 | 版本 / 状态 | 调用方 / 触发源 | 约束 |
|---|---|---|---|---|---|
| 注入流程 | `packages/injector/src/inject.ts#inject` | CLI | `node packages/injector/dist/agent-feedback.mjs inject <目录>` | 维护者 | 顺序：前置检查（宿主名称先过 `packages/shared/src/skill-name.ts#validateSkillName`，不合法即失败、不发请求不写文件） → 备份旧模块 → 写文件 → 令牌泄漏检查 → 登记；重复注入幂等 |
| 引导语标记 | `packages/injector/src/inject.ts#MARKER` | 内部 | canonical | 注入 | 正文已含标记则不重复追加；引导语只追加不改写原文 |
| 命令入口与参数 | `packages/injector/src/cli.ts#main` | CLI | config、inject | 维护者 | 登记令牌只从标准输入读，不接受命令行参数 |
| 本机配置 | `packages/injector/src/config.ts#writeConfig` | 内部 | canonical | config 命令 | 权限 0600；路径 Windows 用 APPDATA，其余用 ~/.config |
| 登记客户端 | `packages/injector/src/registry-client.ts#checkName` | 内部 | canonical | 注入 | 调用登记域的两个接口，10 秒超时，错误转成中文原因 |

## 陷阱项
- 把登记令牌写进宿主目录 — 令牌只存本机配置；`packages/injector/src/inject.ts#inject` 写完文件后会扫描并回滚，宿主里写的是 endpoint 与 moduleVersion
- 对本机 `~/.claude/skills` 下的安装副本注入 — 重装会被整目录覆盖，注入对象必须是 skill 源头目录
- 宿主没声明 name 仍注入 — 直接拒绝，名称必须由宿主声明，不从目录名推断
- 用旧名注入 — 服务回 old_name，先把宿主声明改成现名，见 `packages/server/src/routes/registry.ts#registerRegistryRoutes`
- 忘记先构建模块 — 缺 `packages/module/dist/submit.mjs` 时注入报错要求先构建，不会退回读 src
- 认为注入会处理宿主仓库的门禁 — 目录白名单、规范句去重、体积预算等由维护者按宿主仓库流程补，见 `engineering-context/dependencies/host-skills/分发与门禁.md`
