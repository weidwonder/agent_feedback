# 业务域卡 — agent-feedback › 反馈模块

## 职责
随宿主 skill 分发的部分：提交脚本（构建为单文件 submit.mjs）与写给使用宿主 skill 的 agent 的规则文件；负责补齐自动字段、本地校验、提交并把结果一行 JSON 输出。

## 权威实现与对外接口

| 能力 / 入口 | 权威实现（cite） | 类型 | 版本 / 状态 | 调用方 / 触发源 | 约束 |
|---|---|---|---|---|---|
| 提交脚本 | `packages/module/src/submit.ts#main` | 内部 | canonical | 宿主 skill 内的 agent | 只向标准输出写一行 JSON，退出码恒为 0，不写标准错误；10 秒超时；Node 主版本低于 20 回 `node_too_old`（`packages/module/src/node-version.ts#nodeTooOld`） |
| 宿主名称与版本读取 | `packages/shared/src/frontmatter.ts#parseFrontmatter` | 内部 | canonical | 提交脚本、注入工具 | 只认顶层 name 与 metadata 下的 version；读不到 name 则 host_unreadable |
| 提交前校验 | `packages/shared/src/validate.ts#validateSubmission` | 内部 | canonical | 提交脚本 | 与服务端同一份，客户端通过不代表服务端一定收 |
| agent 行为规则 | `packages/module/assets/FEEDBACK.md` | 文档 | canonical | 宿主 agent | 每会话最多 2 次、全程静默、禁写清单在第 6 节 |
| 隐私说明 | `packages/module/assets/PRIVACY.md` | 文档 | canonical | 使用者 | 发送范围变化时必须同步 |
| 运行时配置 | `packages/module/src/submit.ts#readText` | 内部 | canonical | 提交脚本 | 读脚本同目录 config.json 的 endpoint 与 moduleVersion，缺失即 not_configured |

## 陷阱项
- 在提交脚本里另写校验或长度限制 — 改用 `packages/shared/src/validate.ts#validateSubmission`，脚本只补时间、系统、宿主名版本、模块版本这几个自动字段
- 让 agent 填 skill 名、时间、系统、模块版本 — 这些由脚本补齐，agent 多填字段整次提交因未知字段被拒
- 让脚本非零退出或写标准错误 — 会打断使用者任务，失败一律以 `ok:false` 加原因码报告
- 直接运行 `packages/module/src` 下的 TypeScript — 宿主拿到的是构建产物 `packages/module/dist/submit.mjs`（由 package.json 的 build 生成），注入前必须先构建
- 在 `packages/module/assets/gitignore` 之外放运行时数据 — 宿主目录里的 `.runtime/` 被它忽略，别的落盘会被宿主仓库带进版本控制
