# 业务域卡 — agent-feedback › 管理界面

## 职责
维护者的服务端渲染后台（/admin）：单管理员账号登录、反馈筛选与处理、登记名单管理、令牌创建撤销与改密码。

## 权威实现与对外接口

| 能力 / 入口 | 权威实现（cite） | 类型 | 版本 / 状态 | 调用方 / 触发源 | 约束 |
|---|---|---|---|---|---|
| 路由与访问控制 | `packages/server/src/admin/routes.ts#registerAdminRoutes` | HTTP | /admin/* | 维护者浏览器 | 所有路由包在 `guarded` 里：POST 先验同源（403），再验会话（未登录 302 到登录页） |
| 页面渲染 | `packages/server/src/admin/views.ts#feedbackListPage` | 内部 | canonical | 路由 | 纯字符串模板，用户内容 MUST 经 `escapeHtml`；CSP 为 default-src 'none'，页面不含脚本 |
| 登记页数据 | `packages/server/src/admin/skills.ts#listSkills` | 内部 | canonical | 登记页 | 近 7 天收录数按提交计，不按问题条数计 |
| 登录失败限额 | `packages/server/src/admin/routes.ts#registerAdminRoutes` | 内部 | 每来源地址每天 20 次 | 登录 | 复用 `counters` 表的 `login_fail:<地址>` 作用域，与提交限额共用北京业务日 |
| 会话 | `packages/server/src/auth.ts#createSession` | 内部 | 有效期 7 天 | 登录、改密 | cookie 存明文 id，库里只存 SHA-256；改密码与命令行重设管理员都会清空全部会话 |
| 北京时间业务日与区间 | `packages/server/src/time.ts#beijingDay` | 内部 | canonical | 筛选、限额、清理、备份 | 业务日、区间换算、到期口径的唯一权威 |
| 北京时间显示格式化 | `packages/server/src/admin/views.ts#formatFull` | 内部 | canonical（仅显示） | 列表与详情页 | time.ts 没有显示格式化函数，显示只走 `formatFull` 与 `formatShort` |
| 中文显示名 | `packages/shared/src/labels.ts#LABELS` | 内部 | canonical | 页面渲染 | 类型、影响、状态、来源的中文名只在这里 |

## 陷阱项
- `packages/server/src/admin/views.ts#formatShort` 与 `formatFull` 各自内联 `8 * 3600 * 1000` — 与 `packages/server/src/time.ts` 里未导出的 `BEIJING_OFFSET_MS` 是重复的偏移常量。业务日、区间、到期判断以 time.ts 为权威，显示格式化只有 views.ts 这两处；修改北京时区口径时两边必须同时改，或先把常量从 time.ts 导出后收敛
- 在 views 或 routes 里另写中文显示名或枚举列表 — 改用 `packages/shared/src/labels.ts#LABELS` 与 `packages/shared/src/limits.ts#STATUSES`
- 新增 POST 路由不套 `guarded` — 会绕过同源与会话校验
- 在页面里加内联脚本或外链资源 — 会被 CSP 拦截，交互靠表单与 :target 完成
- 列表默认只看待处理 — 状态默认值是 pending、时间范围默认近 7 天，排查"看不到反馈"先看这两个筛选，见 `packages/server/src/admin/routes.ts#parseListForm`
