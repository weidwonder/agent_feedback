# 管理界面

维护者的网页后台：查看与处理反馈、管理 skill 登记、管理令牌与密码。路由与会话约定的契约见技术 spec `docs/spec/2026-09-29-agent-feedback-eng-spec.md` §3，视觉与交互参考原型 `docs/spec/2026-09-29-agent-feedback-prototype.html`。上级：[REQUIREMENTS](../REQUIREMENTS.md)。

## 登录与密码

| 功能 | 规则 |
|---|---|
| 账号 | 单一维护者账号，在部署时用服务自带命令设定；界面不提供注册和找回密码，忘记密码时由维护者在服务器上重跑该命令重置，重置会使所有已登录会话失效 |
| 访问控制 | 未登录时一律不可访问管理界面的任何页面（除登录页）；已登录访问不存在的页面显示 404 页 |
| 登录失败 | 账号或密码错误时提示「账号或密码不正确」；同一来源地址当天失败 20 次后，当天拒绝继续尝试并提示今天登录失败次数过多、请明天再试 |
| 登录有效期 | 登录后 7 天内有效，可主动退出 |
| 修改密码 | 需输入当前密码，当前密码错误时不能修改；新密码至少 12 个字符；修改后旧密码无法登录，所有已登录会话失效 |

## 反馈列表与详情

- 列表按收录时间倒序，每页 20 条；默认只显示待处理，时间范围默认近 7 天，状态可选「全部」。
- 可按 skill、反馈类型、影响程度、处理状态、是否已解决、收录时间范围（近 7 天、近 30 天、近 6 个月，或自定义起止日期）、反馈模块版本、agent 名称、运行环境名称组合筛选，结果同时满足所有条件。近 7 天、近 30 天含今天在内的 7、30 个北京自然日。
- 没有符合条件的反馈时提示没有符合条件的反馈，并给出清除全部筛选的入口。
- 详情页：该条问题（类型、影响、状态、是否已解决、描述、推荐解法、本会话出现次数、收录时间）在上，所属提交的会话信息（skill 与版本、反馈模块版本、任务概要、用户信息及其已知或猜测、操作系统、agent、运行环境、会话编号）在下；列出相关 skill 与同一次提交的其他问题，可跳转查看。

## 标记与删除

- 标记状态：可改为五种状态中的任一种，成功后显示已标记为哪个状态。
- 删除：可删除单条反馈；删除前须二次确认，确认框提示删除后界面和查询通道都查不到、且不可恢复；删除后回到列表并提示已删除的编号。备份里的副本随备份过期消失，规则见 [收集服务与把关](收集服务与把关.md)。

## skill 登记

- 列出已登记的 skill：名称、收录开关（启用或停用）、登记时间、近 7 天收录数（含今天的 7 个北京自然日）、各反馈模块版本的提交数（统计全部保留期内的收录）；没有登记时显示空态。
- 可启用、停用；不能在界面上新增登记，新增登记的方式是对 skill 的源头运行注入工具（页头有此说明）。
- **改名**：新名称须与宿主 skill 自己声明的名称完全一致，且不能与已登记的其他 skill 现名重名，也不能与其他 skill 的旧名冲突；改名须二次确认（取消则名称不变），确认框说明该 skill 的历史反馈条数将归到新名称下、仍以旧名称提交的反馈将不再收录；确认后历史反馈归到新名称下，此后以旧名称提交的反馈不再收录。改名的完整顺序：先改宿主 skill 自己声明的名称，再在界面把登记改成同一个新名称，之后才能对它重新运行注入工具。
- **拒收次数**：登记页按天、按原因（超出限额、未登记或已停用、格式不合格）显示近 7 天的全站拒收次数。

## 令牌

- 可生成两种令牌：查询令牌（供维护 agent 查询与标记状态）、登记令牌（仅供注入工具登记，不能查询反馈）。生成时须填名称。
- 令牌只在生成时完整显示一次，关闭后无法再查看。
- 令牌列表显示名称、类型、创建时间、最近使用时间。
- 撤销后立即失效，之后的查询或登记一律拒绝。
- 只有已登录的管理界面能生成、撤销令牌，查询令牌不能管理令牌。

## 不做

只有一个维护者账号，不做多账号、权限分级和统计图表；不提供新增登记和调整限额的界面。
